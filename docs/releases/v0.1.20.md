# v0.1.20

## 本版亮点

- 搜索页新增「搜索记录」：搜索过的关键词会自动保存，点一下就能重新搜，单条可删、也能一键清空。
- 继续修搜索翻页：放宽翻页链接识别，并在缺少页码链接时用搜索会话 id 兜底重建。

## 新增

- 搜索记录：搜索成功后自动保存关键词（按最近使用排序、自动去重、最多 30 条）。
- 记录以胶囊形式展示在搜索页，点一下填入并重新搜索；每条右侧有 × 可单独删除，右上角「清空」清掉全部。
- 搜索记录只存在本机，不涉及账号同步。

## 修复

- 修复搜索翻页一直失败的问题。之前只认 href 里带 `search.php` 的翻页链接，而论坛的搜索分页也会输出相对形式（`?searchid=…&page=2`），导致分页条能出现但每次翻页都找不到链接。现在放宽为「任何带 `page=N` 且不属于其他列表页的链接」。
- 新增兜底：若页面没有明确给出某一页的链接，用解析到的搜索会话 id 重建 `search.php?searchid=…&page=N`。
- 翻页拿到的新页面若带有新的会话 id，会同步更新，避免后续页继续用旧 id。

## 技术说明

- `SearchResultPage` 增加 `searchId`，`SearchResultParser.parsePage` 从页面中提取。
- `searchThreads` 翻页时优先用页面给出的链接，缺失则用 `searchId` 兜底；`_searchId` 在每次搜索结果页后刷新。
- 新增 `SearchHistoryStore`（shared_preferences + JSON，去重、最近优先、上限 30、坏数据容错）。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面会继续提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
