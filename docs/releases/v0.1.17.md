# v0.1.17

## 本版亮点

- 修复「检查更新」指向错误仓库的问题：应用现在检查本仓库的 Releases，不再永远提示旧版本。

## 修复

- 修复应用内「检查更新」始终查到上游旧版本（v0.1.15）的问题。更新检查里写死的仓库地址已改为本仓库，之后新版本发布后应用内就能正常检测到。
- 修复 README 里所有版本徽章和下载链接指向错误仓库的问题，现在都指向本仓库的 Releases。

## 技术说明

- `UpdateChecker` 的默认仓库常量从上游改为本仓库；对应的单元测试断言同步更新。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面会继续提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。

> 注意：本版起签名与上游 v0.1.15 及更早版本不一致。从上游版本升级需要先卸载旧版再安装。
