# v0.1.16

## 本版亮点

- 修复付费帖“购买后内容不显示”的问题：茶馆、免空资源区等板块里，购买成功后的下载链接、网盘地址和附件说明现在都会正常显示。
- 出售区块不再把已购内容误判成“购买风险提示”，也不会再把“此帖售价 … 人购买”渲染成一条多余的引用。
- 板块支持按原站的分类标签浏览（如 `fid-128-type-3.html` 这类子分区），标签栏和翻页都跟原站一致。

## 修复

- 修复付费帖购买后正文被整块丢弃的问题。论坛把“购买风险提示”和“已购内容”放在同一个引用槽位里，之前只按样式类名区分，导致购买后的内容被当成警告丢弃；现在改为按提示文本识别，只有真正的风险提示才会隐藏。
- 修复部分板块（已购内容的引用块不带 `jumbotron` 标记）依然显示为空的问题，购买后内容一律按正文渲染，图片、链接、文字全部保留。
- 修复已购出售帖里“此帖售价 … 已有 N 人购买”被当成引用渲染的问题。
- 修复已购出售帖的引用槽位被误当成楼层引用的问题。
- 修复板块分类标签（子分区）翻页丢失筛选条件的问题，翻页后会保持在同一个分类里。
- 修复分类列表页（classic 表格布局）解析不到帖子、只显示子版块入口的问题。
- 修复部分响应编码不标准（声明与实际编码不一致、内容被截断）时正文乱码或解析失败的问题，现在会按声明编码、UTF-8 和本地编码依次回退，并对异常字节容错。
- 修复提示页标题只显示站点品牌时提示信息为空的问题，现在会回退读取页面正文。
- 修复登录页和首页在部分 Flutter 版本下因 `ListTile` 背景断言导致的测试失败与运行期告警。

## 体验优化

- 帖子正文的出售区块、附件、图片、下载信息和引用现在走同一条渲染链，复杂楼层的前后顺序更贴近原站。
- 板块页的分类标签栏和子版块面板同时存在时布局更稳定。
- 补充了出售区块（购买前 / 购买后 / 不带 `jumbotron` 的已购内容）、分类标签、响应编码和提示标题的回归测试，后续改动更不容易把旧问题带回来。

## 技术说明

- 本版把“出售槽位”的判定从样式类名改为内容语义：紧跟出售框的引用块，只有命中购买风险提示文本才丢弃，其余一律按已购内容内联渲染。
- 解析层新增 `ForumThreadFilter` 与分类标签解析，仓库层与 URL 解析层同步支持分类筛选与分页。
- 新增 `forum_body_decoder`，统一处理论坛响应的编码回退与容错解码。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面会继续提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
