# v0.1.19

## 本版亮点

- 修复板块分类（子分区）列表只显示一条置顶、其余帖子全部消失的问题。
- 搜索支持翻页了：之前只能看第一页，现在有完整的页码条（上一页 / 页码 / 跳转 / 下一页）。

## 修复

- 修复「分类筛选」下帖子列表只剩一条的问题。分类页（如 `thread.php?fid-128-type-3.html`）用的是经典表格布局，表格里同时有置顶帖和普通主题；之前用「表格置顶是否为空」来决定走哪套解析，而置顶帖本身就让判断结果非空，于是永远回退不到表格解析，普通主题被整批丢掉。现在改为由「是否处于分类筛选」直接决定。
- 修复搜索结果无法翻页的问题，搜索结果页现在会解析页码与翻页链接，并提供与版块页一致的页码条。
- 搜索结果翻页失败（会话内的搜索链接过期）时会提示「请重新搜索」并停留在原页，不会把界面卡在错误态。

## 体验优化

- 分页条抽成公共组件，版块页和搜索页共用同一套交互（页码窗口、跳转弹窗、上一页/下一页），后续新增列表页可以直接复用。

## 技术说明

- `fetchBoardThreadPage` 在带 `filterUrl` 时直接采用经典表格解析结果，普通版块仍保持「只读 wall 流」的行为，避免把更上层置顶和公告混进列表。
- `searchThreads` 改为返回带分页的 `ForumThreadPage`；翻页跟随结果页自己打印的链接（phpwind 搜索带会话级 `searchid`，猜查询串不可靠）。
- `SearchResultParser` 新增 `parsePage`，解析 `Pages: X/Y`、当前页与各页链接。
- 分页条从 `board_thread_list_widgets.dart`（`part of` 屏幕文件，无法被 import）抽到 `features/common/pagination_bar.dart`。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面会继续提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
