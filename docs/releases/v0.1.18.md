# v0.1.18

## 本版亮点

- 个人中心新增「已购买的帖子」：在本 App 内购买过付费内容的帖子会自动记录，随时回去翻。

## 新增

- 「我的 → 已购买的帖子」：列出在本 App 内成功购买过内容的主题，显示标题、SP 币价格、帖子 tid 和购买时间，点一下直接回到该帖。
- 每条记录支持单独移除，右上角也可以一键清空本机记录。

## 说明

- 论坛本身**没有**「已购买主题」页面（个人页的标签只有 资料 / 主题 / 回复 / 收藏 / 好友 / 商品），所以这份列表是**本机记录**：
  - 只有**在本 App 内**点「购买查看」成功的帖子才会被记录；
  - 在网页版或其他设备上买的，这里不会出现；
  - 清空记录只影响本机，不会影响论坛上的购买状态。

## 技术说明

- 新增 `PurchasedThread` 模型与 `PurchaseHistoryStore`（shared_preferences + JSON，按 tid 去重、新的在前、上限 200 条）。
- 购买成功（`buySaleBox` 返回成功）后写入记录，写入失败不会影响购买流程。

## 发布说明

- 本版本继续由 GitHub Actions 自动构建 Android、iOS 和 Windows 安装包。
- Release 页面会继续提供 Android 多架构 APK、AAB、iOS sideload IPA、Windows x64 压缩包和 SHA256 校验文件。
